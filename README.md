# PC Shutdown Timer

A simple, lightweight batch script for Windows to schedule PC shutdown or reboot. 

Простой и легкий скрипт (батник) для Windows для планирования выключения или перезагрузки ПК.

## Features / Особенности
- **No Installation Required / Не требует установки**: Just run the `.bat` file.
- **Interactive Menu / Интерактивное меню**: Easy to use interface.
- **Custom Timer / Настраиваемый таймер**: Set a shutdown/reboot timer in minutes or hours.
- **Cancel Anytime / Отмена в любой момент**: Easily cancel an existing shutdown timer.

## How to Use / Как использовать
1. Download the latest release from the [Releases page](https://github.com/Sto3IV/shutdown-timer_PC/releases). / Скачайте последний релиз.
2. Extract the files and double-click `shutdown-timer.bat`. / Запустите `shutdown-timer.bat`.
3. Follow the on-screen instructions. / Следуйте инструкциям на экране.
