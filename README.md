# PC Shutdown Timer

A simple, lightweight batch script for Windows to schedule a PC shutdown or reboot. 

## Features
- **No Installation Required**: Just run the `.bat` file.
- **Interactive Menu**: Easy to use command-line interface.
- **Custom Timer**: Set a shutdown/reboot timer in minutes or hours.
- **Cancel Anytime**: Easily cancel an existing shutdown timer from the menu.

## How to Use
1. Download the latest release from the [Releases page](https://github.com/Sto3IV/shutdown-timer_PC/releases).
2. Extract the files and double-click `shutdown-timer.bat`.
3. Follow the on-screen instructions.
